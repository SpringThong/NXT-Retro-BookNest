# Đăng các gói cài lên Releases

Tài liệu này dành cho tác giả. Repo đã có phần giới thiệu và hướng dẫn; các ZIP ứng dụng sẽ được bạn tải lên riêng.

## Đăng bản 1.0.2

1. Mở tab **Releases** của repo, chọn **Draft a new release**.
2. Tạo/chọn tag `v1.0.2`, đặt tiêu đề **NXT Retro BookNest 1.0.2**.
3. Đính kèm sáu ZIP đúng tên trong bảng dưới.
4. Ghi thay đổi chính, kiểm tra gói cài rồi chọn **Publish release** khi bạn sẵn sàng.

| Máy / ROM | Tệp đính kèm |
| --- | --- |
| Brick Pro / Stock | `NXT_Retro_BookNest_v1.0.2_BrickPro_Stock.zip` |
| Brick Pro / NX Redux | `NXT_Retro_BookNest_v1.0.2_BrickPro_NXRedux.zip` |
| Brick Pro / NextUI | `NXT_Retro_BookNest_v1.0.2_BrickPro_NextUI.zip` |
| Brick Pro / Knulli | `NXT_Retro_BookNest_v1.0.2_BrickPro_Knulli.zip` |
| Brick Pro / muOS | `NXT_Retro_BookNest_v1.0.2_BrickPro_MuOS.zip` |
| R36S / DarkOS | `NXT_Retro_BookNest_v1.0.2_R36S_DarkOS.zip` |

Giữ tên khác nhau theo ROM để người dùng chọn đúng. Mỗi gói đã kèm hướng dẫn `CAI_DAT_ROM.md`. Trang tải trong README trỏ tới danh sách Releases, nên chưa cần thay liên kết trực tiếp cho từng tệp.

GitHub tự tạo các mục “Source code (zip/tar.gz)” từ nội dung repo. Với repo tài liệu này, chúng chứa tài liệu chứ không phải ứng dụng. Người dùng cần tải ZIP cài đặt theo máy/ROM.

Sau khi các ZIP đã được đăng, có thể cập nhật dòng thông báo “các gói cài sẽ được tác giả đính kèm” trong `README.md` và `README.vi.md` thành thông báo đã phát hành.
